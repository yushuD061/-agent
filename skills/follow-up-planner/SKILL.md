# Follow-Up Planner

Plan from the latest relevant contact.  Unanswered A/B may use D+3, D+7, D+14.
Paused, unsubscribed, and D prospects receive no task.  Each task includes due
date, type, reason, whether a draft is needed, and `human_review_required: true`.
Tasks are reminders only and never send messages.
