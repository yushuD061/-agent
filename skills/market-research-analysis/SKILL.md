# 市场调研分析

执行固定且可追溯的调研链路：先明确决策问题，再搜集与验证证据，最后综合判断。不得把搜索摘要、宣传材料或模型常识当作已证实事实。

## 必读参考

- 开始检索前读取 [references/research-brief.md](references/research-brief.md)，建立调研简报和检索矩阵。
- 登记、筛选和交叉验证资料时读取 [references/source-and-evidence-rules.md](references/source-and-evidence-rules.md)。
- 处理竞品、报告、问卷或访谈时读取 [references/analysis-methods.md](references/analysis-methods.md)。
- 生成交付物前读取 [references/output-contract.md](references/output-contract.md)。

## 固定工作流

严格按阶段执行。若决策问题、范围或关键数字来源不清，不得生成确定性结论；将缺口记为 `pending_confirmation`。

### 1. 定义决策问题

1. 把宽泛主题改写成 1–3 个可回答的决策问题，例如“是否进入该市场”“优先服务哪类客户”“竞品薄弱点在哪里”。
2. 确认产品/品类边界、地区、客户类型、时间窗口、币种/单位和报告用途。
3. 确认竞品集合和比较维度；区分直接竞品、间接竞品和替代方案。
4. 若用户未指定，先输出合理的暂定范围并标记为假设，不擅自无限扩展搜索。

### 2. 制定研究计划

1. 将每个决策问题拆成子问题、所需证据、候选来源、检索词和完成标准。
2. 同时规划一手研究与二手研究；只有公开资料时明确“桌面研究”边界。
3. 设定资料截止日期和时效阈值。动态数据优先使用最新可核实资料，历史判断保留当时版本。
4. 预先定义停止条件：核心问题已有多源支持，新增来源不再显著改变判断，或预算/时间上限已达到。

### 3. 搜集并登记资料

1. 优先使用官方原始来源：公司官网、定价页、产品文档、更新日志、监管披露、财报、政府/统计机构和原始研究。
2. 用行业报告、权威媒体、研究机构补充市场视角；用用户评论、社区、招聘信息等补充行为信号。
3. 对每条资料记录标题、发布者、原始 URL/文件、发布日期、访问日期、地区、统计口径和适用期间。
4. 不绕过登录、付费墙、robots、安全限制或访问控制；不抓取超出用户授权的私人数据。
5. 不把搜索结果摘要当作引用；关键结论必须打开并核对原始页面或原始文件。

### 4. 质量筛选与证据分级

1. 按来源类型、方法透明度、样本代表性、时效性和利益相关性评估质量。
2. 删除完全重复项；同一新闻稿被多家转载仍视为一个原始来源。
3. 区分事实、来源方主张、分析推断和未知项。
4. 对市场规模、份额、用户数、GMV、增长率、价格等关键数字至少寻找两个独立来源；无法满足时降低置信度。

### 5. 规范化与交叉验证

1. 统一市场定义、地区、期间、币种、含税口径和单位后再比较数字。
2. 为每个数字保留原值、换算方式、原始口径和来源。
3. 若不同来源差异超过 20% 或定义明显不同，登记冲突，不直接求平均。
4. 分析冲突原因：市场边界、统计对象、名义/实际值、财年/自然年、样本、预测年份或发布者利益。
5. 对无法解释的冲突输出区间或并列口径，并标为 `pending_confirmation`。

### 6. 按任务执行分析分支

根据目标选择一个或多个分支，但必须共享同一证据台账。

#### A. 竞品情报

1. 对比定位、目标客户、核心功能、定价、渠道、商业模式、用户反馈、近期战略和可验证经营指标。
2. 区分官方宣称与用户/第三方证据；记录页面版本和观察日期。
3. 生成竞品矩阵和逐家 SWOT。SWOT 的每一项必须有证据或明确标为推断。
4. 竞争格局图的坐标定义、量纲和数据来源必须明确；缺数据时使用定性等级，不伪造精确坐标。

#### B. 行业报告与趋势

1. 从每份报告提取市场定义、基准年、规模、增长率、份额、主要玩家、趋势和预测。
2. 建立逐来源对比表，标出一致结论、冲突数据和假设差异。
3. 计算 TAM/SAM/SOM 时分别说明范围、方法和假设；优先同时给出自上而下与自下而上结果。
4. 不把预测写成事实；展示预测区间、关键驱动和失效条件。

#### C. 问卷与用户画像

1. 检查样本量、招募方式、完成率、缺失值、重复样本、题目偏差和群体代表性。
2. 先做描述统计，再决定是否聚类；样本不足、变量不合适或结果不稳定时不得强行分群。
3. 用户画像保持 3–4 个可行动群体，包含特征、需求、行为、痛点、付费意愿和证据覆盖率。
4. 访谈原话必须去标识化，并保留访谈编号；不得编造引语或把少数个案外推到总体。
5. 分群结果须报告方法、变量、样本量和限制。

### 7. 综合判断与机会评估

1. 按“已证实事实 / 多源一致判断 / 分析推断 / 待确认”组织结论。
2. 将机会映射到目标客群、未满足需求、竞品缺口、市场趋势和企业能力。
3. 使用影响、证据强度、可达性、竞争强度和风险进行排序；明确评分尺度。
4. 每个建议同时列出支持证据、反证、关键假设和下一步最低成本验证动作。

### 8. 生成并复核报告

1. 按输出契约生成研究简报、来源台账、核心对比表、冲突表、分析结果、结论和建议。
2. 每个关键事实和数字紧邻引用；注明发布日或数据期，不能只在文末堆链接。
3. 检查引用能否支持对应主张，图表是否与底表一致，时间和口径是否混用。
4. 生成 200–300 字管理层摘要和 2–5 条可执行建议。
5. 融资、投资、定价、市场进入等高风险决策须由业务负责人复核，并对关键数字回到原始报告确认。

## 执行原则

- 动态市场事实必须实时检索和核验，不依赖模型记忆。
- 优先引用原始来源；二手来源不得伪装成一手证据。
- 不因结论更吸引人而忽略反证、负面样本或不确定性。
- 观察到相关性时不得直接宣称因果。
- 对用户数据执行最小化、去标识化和授权范围控制。
- 网页案例只提供流程启发，不替代专业咨询、法律意见或投资尽调。
