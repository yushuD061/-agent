# 来源与证据规则

## 来源台账字段

| 字段 | 说明 |
|---|---|
| `source_id` | 唯一编号 |
| `title` | 页面、报告或数据集标题 |
| `publisher` | 发布主体 |
| `source_type` | 官方、监管、统计、行业研究、媒体、用户、社区等 |
| `url_or_file` | 原始 URL 或本地文件路径 |
| `published_at` | 发布或更新日期 |
| `accessed_at` | 实际访问日期 |
| `data_period` | 数据对应期间 |
| `market_scope` | 地区、对象和市场定义 |
| `method_sample` | 方法与样本（若公开） |
| `claim` | 该来源支持的具体主张 |
| `quality` | high / medium / low |
| `limitations` | 利益冲突、缺失口径、样本限制等 |

## 证据等级

- `high`：权威原始数据或正式披露，方法和口径清晰且时效合适。
- `medium`：信誉良好的二手研究或透明样本研究，可用于交叉验证。
- `low`：宣传稿、匿名评论、无方法数字或过期资料，只能作线索或定性信号。

来源等级不等于结论置信度。结论置信度还取决于独立来源数量、口径一致性、反证和推断距离。

## 独立性判断

- 多个页面引用同一报告或新闻稿时只算一个来源。
- 同一集团旗下媒体或同一数据供应商的再包装不自动视为独立。
- 公司官网适合证明自身定价和功能，不宜单独证明行业领先或客户满意。
- 评论平台可以呈现痛点信号，不能代表整体用户比例，除非抽样方法支持。

## 冲突记录

| 指标 | 来源 A | 来源 B | 差异 | 口径差异 | 解释 | 状态 |
|---|---|---|---:|---|---|---|

状态使用 `resolved` 或 `pending_confirmation`。不得为了得到单一答案而隐去冲突。

## 引用规则

- 引用原始详情页，而不是搜索结果页。
- 每个关键数字附来源、数据期和统计口径。
- 引用内容必须实际支持主张；不要用仅相关但不支持的页面。
- 无法访问原文时明确说明“仅见二手转述”，降低置信度。
