# Prospect Scoring

Score product fit 0-40, channel value 0-20, decision-maker access 0-15,
target-market value 0-10, website quality 0-10, and risk adjustment 0 to -10.
A=80-100, B=60-79, C=40-59, D=0-39.  `fetch_failed`/`no_evidence` is capped at
D; A/B requires fetched product or channel evidence.  Explain every deduction.
