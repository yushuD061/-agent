# 指标与规则

## 核心公式

| 指标 | 公式 |
|---|---|
| 毛利 | 净销售收入 − 可归属销售成本 |
| 毛利率 | 毛利 ÷ 净销售收入 |
| 费用率 | 期间费用 ÷ 净销售收入 |
| 回款率 | 期间已核销收款 ÷ 期间应收金额 |
| 逾期率 | 逾期应收余额 ÷ 应收余额 |
| DSO | 期末应收余额 ÷ 期间赊销收入 × 期间天数 |
| 客户集中度 Top N | 前 N 客户收入 ÷ 总收入 |
| 预算偏差 | 实际金额 − 预算金额 |
| 预算偏差率 | (实际金额 − 预算金额) ÷ 预算金额 |

分母为零时输出 `N/A` 并解释，不输出无穷大或伪造的 0%。

## 应收账龄

默认按报告截止日减到期日分桶：未到期、1–30 天、31–60 天、61–90 天、90 天以上。企业口径不同时以经确认口径为准。

## 变化分析

- 环比：本期对紧邻上期。
- 同比：本期对去年同期。
- 同时报告绝对差额和变化率；基数过小时优先解释绝对差额。
- 毛利变化至少检查售价、销量、产品/客户组合、采购成本、国际物流与关税、折扣和汇率。

## 默认异常候选规则

以下仅是候选筛查阈值，用户或企业规则优先：

- 费用科目增长率绝对值超过 20%。
- 单笔金额与同类历史中位数偏差显著。
- 同一单据号重复、同金额同日期重复收付。
- 收款超过发票未核销余额。
- 汇率偏离同币种同日基准或汇率日期缺失。
- 毛利率突然转负或较基准下降超过 5 个百分点。
- 应收超过 90 天或单一客户集中度异常升高。

每个异常必须输出规则、实际值、基准值、影响金额和需要的确认动作。

## 汇率与汇兑

- 交易折算、期末重估和实际结算使用的汇率可能不同，必须分别记录。
- 只有具备原始确认汇率与结算汇率时才计算已实现汇兑损益。
- 数据不完整时只做“汇率变动影响估算”，不得记为会计确认的汇兑损益。
